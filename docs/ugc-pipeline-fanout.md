# Ugc Pipeline Fanout

Pipeline: ugc_pipeline.py (plus regen_feedback.py for targeted re-dos). Deliverables so far: Downloads/final_v2 (five clips for the Fanout script), earlier round in Downloads/final.

Rules the user settled on (Oct 24 2026):
- Every clip starts from the same first frame (first_frame.png); no chained start frames.
- No automated quality gate or re-rolls; the user reviews clips themselves. Generate, then voice-swap.
- Clip duration follows word count, kept TIGHT: up to 9 words 4 s, 10 to 14 words 6 s, 15 or more 8 s. The user's Oct 24 feedback on the "cheat code for engineers" set was that every clip looked very slow-paced; the looser rule (8-11 words 6 s, 12+ 8 s) gave Veo room to stretch the delivery. Prompt pace wording is now "brisk, lively conversational pace, quick and fluent, no pauses between phrases" (hook: "fast, excited"), and "slow speech, slow motion, drawn-out words" are in the negatives. Err on the shorter bucket; the user trims the hold in the edit (see [ugc-cut-style](ugc-cut-style.md)).
- Speed-up is OFF (--speed defaults to 1.0). A 1.15x post speed-up was tried on the "more than youtube tutorials - kitchen" set on Oct 24 and the user said "dont speed up"; the untouched takes were re-voiced at normal speed. Fix pace through prompt wording and the tight duration buckets only; the speed_up() helper stays in the pipeline but is not used unless the user asks.
- Model google/veo-3.1-fast, 1080p, 9:16, native audio, negatives passed via the negativePrompt passthrough, seed 7 (vary the seed on any re-roll, since the same seed returns a byte-identical video).
- Voice: ElevenLabs speech-to-speech, voice "Sarah" EXAVITQu4vr4xnSDxMaL pinned in Downloads/voice_id.txt, model eleven_multilingual_sts_v2, output must be mp3_44100_192 (raw PCM output is Pro-tier only on this account). The ElevenLabs key lacks voices/models read permissions, so premade voice IDs are used directly.
- URLs in lines are written phonetically for Veo ("Fanout dot ess aitch"), because "Fanout.sh" and "S-H" were voiced as "shhh"/"ish".
- Delivery (Oct 24, latest): prompts now follow [ugc-delivery-reference](ugc-delivery-reference.md). Body clips: face reacts per phrase (eyebrows jump, eyes widen on the key word, mouth wide on stressed vowels, head tilt/nod, real smile when the line lands); free hand gestures continuously at chest height and hits the stressed words (open palm to camera, fingers spread on numbers, point on "not/no", sweeps while listing), never resting in the lap. Pace: "fast and fluent like a real influencer talking to camera, tiny beat after the key phrase, strong emphasis on key words". Beats are gesture-led (BEATS list) and BEAT1 brings the free hand up to chest height in the first second. Hook ([ugc-hook-rule](ugc-hook-rule.md)) is the same style a notch up: lit up, eyebrows up, eyes wide, real smile, head tilt in. Negatives no longer suppress hands or smiles; they target frozen face, blank stare, deadpan, hands still in lap, robotic, presenter voice. Earlier wordings (relaxed/no big expressions; then "naturally expressive, hands in lap, light nod") are superseded.

**Why:** these came from several rounds of the user's feedback; re-deriving them wastes paid generations.
**How to apply:** keep these defaults for the next script unless the user changes them; edit results per [ugc-cut-style](ugc-cut-style.md).
