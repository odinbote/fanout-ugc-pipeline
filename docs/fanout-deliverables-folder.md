# Fanout Deliverables Folder

Every new script gets its own folder in ~/Documents/fanout/AI ugc/ (the "AI ugc" parent holds all AI-generated UGC sets), named after the script (a short phrase from its hook line, e.g. "cheat code for engineers"). Put the final clips (clip_NN_final.mp4), first_frame.png, script.txt, voice_id.txt and the clip prompt files there. Inside AI ugc so far: "cheat code for becoming a better engineer" (the Oct 24 final_v2 set) and "cheat code for engineers" (Oct 24 second script). Other folders in ~/Documents/fanout ("21 oct", "AI trial", "Fanout XML Last Raw", "netflix") are the user's own work; leave them alone.

**Why:** the user asked for a folder per script, named by the script, saved in the fanout folder in Documents, so deliveries are findable alongside their other Fanout work.
**How to apply:** in step 8 of [ugc-workflow](ugc-workflow.md), deliver into ~/Documents/fanout/AI ugc/<script name>/ instead of a Downloads final_vN folder; keep Downloads working folders as scratch.
